# Calculadora de Empréstimo Imobiliário

# Objetivo
- Criar um site para fins de aprendizagem em Python e JavaScript, utilizando frameworks modernos como Agno e Angular CLI, com foco em cálculos de simulação de empréstimos imobiliários, integrado com um agente de inteligência artificial com função de consultor de investimentos.

# Funcionalidades e detalhes planejados do site
- Textos curtos e simples para fácil entendimento
- Design responsivo
- Landing Page
- Página de simulação de empréstimos
- Página do agente de IA

# Funcionalidades planejadas do agente de IA
- Chat de texto
- Chat de voz
- Pesquisa profunda
- Integração com Excel


  # Tecnologias a serem utilizadas
  - Javascript
  - Angular CLI
  - Python
  - Pandas
  - Numpy
  - Agno
